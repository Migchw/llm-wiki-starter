Second Brain ไม่ใช่ที่เก็บโน้ต

มันคือระบบภายนอกที่ช่วยเก็บหลักฐาน, เชื่อมการคิดข้ามเวลา, และส่ง context ที่ไว้ใจได้ให้ AI ช่วยทำงานต่อ

  • จำว่าเรารู้อะไร และรู้มาจากไหน
  • ทบทวน thesis เมื่อหลักฐานใหม่เข้ามา
  • ลดการเริ่ม research จากศูนย์ทุกครั้ง

YAML Frontmatter = ป้ายข้อมูลของโน้ต

---
type: source-note
status: draft
sources: ["[[raw-20260813-earnings-call]]"]
confidence: medium
verification: pending
tags: [thai-stock, earnings]
---

Schema ไม่ทำให้ AI ฉลาดขึ้นเอง แต่ลดการเดา: รู้ว่าโน้ตเป็นอะไร, อยู่ขั้นไหน, อ้างอะไร และยังต้องทำอะไร

Links, backlinks และ Knowledge Graph

[[source-company-call]] → [[operating-leverage]] → [[thesis-company-a]]

Graph คือภาพของ notes และ wikilinks. มันมีค่าเมื่อ link ระบุความสัมพันธ์จริง เช่น source สนับสนุน concept—not when every note links to everything.

Backlink ช่วยย้อนถามว่า “ใครใช้ข้อมูลนี้อยู่?”

Workflow 1 source

  1. Ingest: Raw + URL/date/conversion method
  2. Distill: Source note แยก fact / interpretation / question
  3. Verify: ตัวเลขหรือ quote ที่เปลี่ยน thesis → primary source
  4. Synthesize: concept/entity/thesis ที่ใช้ซ้ำได้
  5. Link, update Index และ append Log

MarkItDown ใช้เมื่อไหร่?

ใช้แปลง PDF/DOCX/PPTX/XLSX/HTML เป็น Markdown เพื่อค้นและให้ LLM อ่าน

ไม่ใช่ fact-checker: PDF scan, ตาราง, multi-column และ footnote อาจเพี้ยน ต้องเก็บต้นฉบับและตรวจตัวเลขสำคัญเสมอ

คุยกับ AI ให้ช่วยได้ดีขึ้น

Prompt ทุกงานควรบอก: Context + Role + Scope + Evidence policy + Output

อ่าน AGENTS.md, Home และ [[source-x]]
Role: Feynman fact auditor
Scope: ตรวจตัวเลขใน [[thesis-company-a]] เท่านั้น
Evidence: primary source; ตรวจไม่ได้ให้ flag pending ห้ามเดา
Output: claim | source/location | verdict | correction needed
ห้ามแก้ Raw หรือ thesis ต้นฉบับ

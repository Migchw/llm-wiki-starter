# Wiki: ความรู้ที่ผ่านการสังเคราะห์

- `Sources/` — สรุป 1:1 ของ raw source
- `Concepts/` — แนวคิดที่ใช้ข้ามบริษัท/ช่วงเวลาได้
- `Entities/` — บริษัท คน กองทุน องค์กร
- `Theses/` — มุมมองลงทุนพร้อม contrary case
- `Synthesis/` — คำตอบ/เปรียบเทียบจากหลาย source

อย่าสร้าง concept เพียงเพราะคำหนึ่งน่าสนใจ: ต้องมี implication, boundary และแหล่งอ้างอิง.
